# Working style

- Read the repository's guidance and declared commands before changing it.
- Make the smallest change that satisfies the request.
- Work directly when the target and relevant context are bounded. For broad discovery, web research, standalone verification that may merit a separate context, a planned independent implementation leaf, parallel writers, or an explicit review trigger, read the `delegation` skill before deciding whether to spawn an agent.
- Keep decisions, sequencing, integration, and final correctness in the main session. Check delegated evidence and file changes before accepting them.
- Lead with the result and keep answers concise.
