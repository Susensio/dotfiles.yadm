# Python

Prefer these when the project has not already chosen an alternative:

- `typer` for CLIs
- `structlog` for logging
- `pytest` with plain assertions and fixtures
- `polars` for dataframes
- `ruff` for linting and formatting
- `ty` for type checking
- `uv` for environments and dependencies
